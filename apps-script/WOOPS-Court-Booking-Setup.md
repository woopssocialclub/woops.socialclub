# WOOPS Court Booking — ระบบจองคอร์ทเทนนิส

ระบบจองคอร์ท 5 คอร์ท (C1–C5) เปิด 06:00–23:00 ทุกวัน จองเป็นรายชั่วโมง
ผู้ใช้แต่ละระดับมีสิทธิ์ต่างกัน เช่น แอดมินจองล่วงหน้าได้ 30 วัน ผู้ใช้ทั่วไปจองได้แค่วันนี้กับพรุ่งนี้

| ส่วน | ไฟล์ | อยู่ที่ไหน |
|---|---|---|
| หน้าเว็บจอง | `booking.html` | เว็บ woops.socialclub (GitHub Pages) |
| ระบบหลังบ้าน | `apps-script/WOOPS_Court_Booking.gs` | Apps Script ที่ผูกกับ Google Sheet |
| ฐานข้อมูล | Google Sheet (แท็บ Users / Bookings / Roles) | Google Drive ของเจ้าของระบบ |

> 🆕 ก่อนต่อหลังบ้าน `booking.html` จะทำงานใน **โหมดทดลอง**: ข้อมูลเก็บใน browser เครื่องนั้นเท่านั้น
> ใช้ลองกดดูได้ทันที (แอดมิน `0800000001 / admin123` · สมาชิก `0800000002 / member123` · ทั่วไป `0800000003 / user123`)

## วิธีติดตั้ง

### 1. สร้างชีทและวางโค้ด

1. เปิด [sheets.new](https://sheets.new) → ตั้งชื่อชีท เช่น **WOOPS Court Booking**
   (ล็อกอินด้วยบัญชีที่จะเป็น "เจ้าของระบบ" — ข้อมูลการจองทั้งหมดจะอยู่ในชีทนี้)
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมออกให้หมด (Ctrl+A → Delete) → วางเนื้อหาจาก `WOOPS_Court_Booking.gs` → Ctrl+S
4. ที่ดรอปดาวน์ข้างปุ่ม Run เลือกฟังก์ชัน **`setup`**
   ⚠️ ต้องเป็น `setup` เท่านั้น ฟังก์ชันอื่นเป็นตัวช่วย รันเดี่ยว ๆ จะ error
5. กด **Run** (▶) → ครั้งแรกจะขอสิทธิ์:
   **Review permissions** → เลือกบัญชี → ถ้าขึ้น "Google hasn't verified this app"
   ให้กด **Advanced** (ข้อความเล็ก ๆ ด้านล่างซ้าย) → **Go to <ชื่อโปรเจกต์> (unsafe)** → **Allow**
   ❗ ปลอดภัย เพราะเป็นสคริปต์ของคุณเองที่เพิ่งวางเข้าไป
6. รอ "Execution completed" → กลับไปที่ชีท จะเห็นแท็บ **Users**, **Bookings**, **Roles**

### 2. เปิดเป็น Web App

1. ในหน้า Apps Script กด **Deploy → New deployment**
2. กดไอคอนเฟือง ⚙️ ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า
   - Description: `WOOPS Court Booking v1`
   - **Execute as: Me** (บัญชีของคุณ — สคริปต์จะเขียนชีทในนามคุณ)
   - **Who has access: Anyone** ⚠️ ต้องเป็น *Anyone* ไม่ใช่ *Anyone with Google account* ไม่งั้นหน้าเว็บเรียกไม่ได้
4. กด **Deploy** → ก๊อป **Web app URL** (ลงท้ายด้วย `/exec`)

### 3. ต่อหน้าเว็บเข้ากับหลังบ้าน

เปิด `booking.html` หาบรรทัดนี้ (อยู่ต้น `<script>`)

```js
var API_URL = '';
```

ใส่ URL ที่ก๊อปมา แล้ว commit ขึ้นเว็บ

```js
var API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

แถบเหลือง "โหมดทดลอง" จะหายไป = ต่อหลังบ้านจริงแล้ว

### 4. สร้างบัญชีแอดมิน

เปิดหน้า `booking.html` → **สมัครสมาชิก** ด้วยเบอร์ของคุณ
**คนแรกที่สมัครจะได้เป็นแอดมินอัตโนมัติ** (เฉพาะตอนที่ยังไม่มีแอดมินในระบบ)
⚠️ ให้สมัครทันทีหลัง deploy ก่อนแชร์ลิงก์ให้คนอื่น

## สิทธิ์แต่ละระดับ (แท็บ Roles)

ค่าเริ่มต้น — **แก้ตัวเลขในแท็บ Roles ได้เลย มีผลทันที** ไม่ต้อง deploy ใหม่

| role | ชื่อที่แสดง | จองล่วงหน้า | ชม./วัน | การจองค้างสูงสุด | ยกเลิกก่อน | จองแทนคนอื่น | ปิดคอร์ท | ยกเลิกของทุกคน | จัดการผู้ใช้ |
|---|---|---|---|---|---|---|---|---|---|
| `admin` | ผู้ดูแล | 30 วัน | ไม่จำกัด | ไม่จำกัด | — | ✅ | ✅ | ✅ | ✅ |
| `member` | สมาชิก | 7 วัน | 2 | 4 | 3 ชม. | | | | |
| `user` | ผู้ใช้ทั่วไป | 1 วัน | 1 | 2 | 6 ชม. | | | | |

ความหมายของคอลัมน์

- `advance_days` — จองล่วงหน้าได้กี่วัน **นับจากวันนี้** (0 = วันนี้อย่างเดียว, 1 = วันนี้ + พรุ่งนี้, 7 = ถึงสัปดาห์หน้า)
- `max_hours_per_day` — จองได้สูงสุดกี่ชั่วโมงต่อวัน (นับทุกคอร์ทรวมกัน) · **0 = ไม่จำกัด**
- `max_active_bookings` — มีการจองที่ยังไม่ถึงเวลาเล่นค้างได้กี่รายการ · **0 = ไม่จำกัด**
- `cancel_before_hours` — ต้องยกเลิกก่อนเวลาเล่นอย่างน้อยกี่ชั่วโมง
- `can_book_for_others` — ใส่ชื่อคนอื่นตอนจองได้ (เช่น แอดมินจองให้โค้ช / ลูกค้าที่โทรมา)
- `can_block` — ปิดคอร์ทได้ (ซ่อมคอร์ท คลาสเรียน จัดแข่ง) ล่วงหน้าได้ถึง 365 วัน
- `can_cancel_any` — ยกเลิกการจองของทุกคน + เห็นชื่อผู้จองในตาราง
- `can_manage_users` — เห็นแท็บ "แอดมิน" เปลี่ยนระดับ / ระงับบัญชี / ตั้งรหัสผ่านใหม่ให้ผู้ใช้

**อยากเพิ่มระดับใหม่** (เช่น `vip`, `coach`) → เพิ่มแถวในแท็บ Roles ใส่ค่าให้ครบทุกคอลัมน์
แล้วไปเปลี่ยน role ของผู้ใช้ในหน้าแอดมิน (หรือแก้คอลัมน์ `role` ในแท็บ Users ตรง ๆ)

> คนที่ยังไม่ล็อกอินดูตารางได้ แต่จะเห็นวันตามสิทธิ์ของ `user` และต้องล็อกอินก่อนจอง

## ใช้งานยังไง

**ผู้เล่น**
- เลือกวัน → แตะช่องว่างในตาราง (เลือกได้หลายช่อง) → **จองเลย** → **ยืนยัน**
- ช่องสีเขียว = การจองของคุณ แตะเพื่อดูรายละเอียด / ยกเลิก
- แท็บ **การจองของฉัน** ดูรายการที่จองไว้และประวัติ

**แอดมิน**
- เลือกช่อง → ตอนยืนยันเลือก **จองสนาม** (ใส่ชื่อผู้เล่นแทนได้) หรือ **ปิดคอร์ท** (ต้องใส่เหตุผล)
- ช่อง "วันอื่น" เลือกวันที่ไกลกว่าแถบวันที่ได้
- ตารางของแอดมินแสดงชื่อผู้จองทุกช่อง แตะเพื่อยกเลิกได้
- แท็บ **แอดมิน** เปลี่ยนระดับผู้ใช้ / ระงับบัญชี / ตั้งรหัสผ่านใหม่ (ผู้ใช้ลืมรหัส → แอดมินตั้งให้ใหม่แล้วแจ้งทาง LINE)

## ข้อมูลในชีท

| แท็บ | เก็บอะไร | แก้มือได้ไหม |
|---|---|---|
| Users | id, เบอร์, ชื่อ, ชื่อเล่น, role, status (`active`/`suspended`), รหัสผ่านแบบเข้ารหัส | ✅ แก้ `role`, `status`, `name` ได้ · ❌ อย่าแตะ `salt`/`password_hash` |
| Bookings | การจองทุกรายการ — ยกเลิกแล้ว **ไม่ลบ** แค่ `status` เป็น `cancelled` | ⚠️ แก้ได้แต่ระวัง ถ้าจะยกเลิกให้แก้ `status` เป็น `cancelled` แทนการลบแถว |
| Roles | สิทธิ์แต่ละระดับ | ✅ แก้ตัวเลข/TRUE-FALSE ได้เลย |

⚠️ **ห้ามเปลี่ยนชื่อหัวคอลัมน์ (แถวที่ 1)** — โค้ดหาคอลัมน์จากชื่อหัว (สลับลำดับคอลัมน์ได้ แต่ห้ามเปลี่ยนชื่อ)

## แก้ค่าได้ในโค้ด (บล็อก "แก้ตรงนี้ได้" ด้านบนสุดของ .gs)

- `COURTS` — ชื่อคอร์ท ถ้าเพิ่ม/เปลี่ยนชื่อคอร์ทแก้ที่นี่ (หน้าเว็บดึงจากหลังบ้านอัตโนมัติ)
- `OPEN_HOUR` / `CLOSE_HOUR` — เวลาเปิด–ปิด (ตอนนี้ 6 กับ 23 = ช่อง 06:00 ถึง 22:00–23:00)
- `NIGHT_FROM_HOUR` — ตั้งแต่ชั่วโมงไหนแสดงไอคอนกลางคืน 🌙
- `SESSION_DAYS` — ล็อกอินค้างไว้ได้กี่วัน
- `MAX_BLOCK_DAYS_AHEAD` — แอดมินปิดคอร์ทล่วงหน้าได้ไกลสุดกี่วัน

⚠️ **แก้โค้ด .gs แล้วต้อง deploy ใหม่ถึงจะมีผล**: Deploy → **Manage deployments** → ✏️ (Edit)
→ Version: **New version** → **Deploy** (URL เดิมใช้ต่อได้ ไม่ต้องแก้ `booking.html`)
ถ้ากด *New deployment* จะได้ URL ใหม่ ต้องไปแก้ `API_URL` ใหม่ด้วย

## ก่อนเปิดใช้จริง

- [ ] รัน `setup` แล้วเห็นแท็บ Users / Bookings / Roles ครบ
- [ ] Deploy เป็น Web app แบบ **Execute as: Me** + **Anyone**
- [ ] ใส่ `API_URL` ใน `booking.html` แล้ว แถบเหลือง "โหมดทดลอง" หายไป
- [ ] สมัครบัญชีแอดมินของตัวเองเป็นคนแรก → เช็คแท็บ Users ว่า role = `admin`
- [ ] ปรับตัวเลขในแท็บ Roles ให้ตรงกับกติกาของสนาม
- [ ] ทดสอบด้วยมือถือ 2 เครื่อง: สมัคร user ธรรมดา → จอง → เช็คว่าอีกเครื่องเห็นช่องนั้นเป็น "ไม่ว่าง"
- [ ] ทดสอบ user จองเกินสิทธิ์ (เกิน 1 ชม./วัน, จองวันมะรืน) → ต้องขึ้นข้อความเตือน
- [ ] แอดมินลองปิดคอร์ท 1 ช่อง แล้วเปิดคืน

## ถ้าเจอปัญหา

- **หน้าเว็บขึ้น "เชื่อมต่อไม่ได้"** → เช็คว่า deploy เป็น *Who has access: Anyone* และ `API_URL` ลงท้ายด้วย `/exec`
- **error "ยังไม่ได้รัน setup()"** → กลับไปรัน `setup` ใน Apps Script (รันซ้ำได้ปลอดภัย ไม่ลบข้อมูล)
- **แก้โค้ดแล้วไม่เปลี่ยน** → ต้อง deploy เวอร์ชันใหม่ (ดูหัวข้อ "แก้ค่าได้ในโค้ด")
- **ผู้ใช้ลืมรหัสผ่าน** → แอดมินเข้าแท็บ "แอดมิน" → **ตั้งรหัสใหม่** แล้วแจ้งผู้ใช้
- **แอดมินลืมรหัสตัวเอง** → ในชีทแท็บ Users เปลี่ยน role ของแอดมินอีกคน (หรือบัญชีสำรอง) เป็น `admin` แล้วใช้บัญชีนั้นตั้งรหัสใหม่ให้
- **ระบบช้าตอนข้อมูลเยอะ** (หลักหมื่นแถว) → ย้ายแถวเก่าในแท็บ Bookings ไปไว้ชีทอื่นเป็นครั้งคราว
  (ต้องเก็บแถวหัวตารางไว้ และอย่าย้ายการจองที่ยังไม่ถึงเวลาเล่น)

## ข้อจำกัดที่ควรรู้

- ไม่มีระบบชำระเงิน / OTP / ส่งอีเมลยืนยัน — ล็อกอินด้วยเบอร์โทร + รหัสผ่าน
- Apps Script ตอบช้ากว่าเว็บทั่วไปเล็กน้อย (~1–2 วินาทีต่อคำสั่ง)
- กันจองชนกันด้วย LockService แล้ว — ถ้าสองคนกดช่องเดียวกันพร้อมกัน คนที่สองจะได้ข้อความ "มีคนจองไปแล้ว"
